# Author Profile

**性质**：**个人偏好层，不是通用规则。** 本文件只服务该位作者的工作流，不得作为所有用户、所有期刊的默认行为。
**与主技能的关系**：`SKILL.md`、`section-guides.md`、`editing-standard.md` 中的通用规则是默认值；本文件在其之上叠加该作者的具体约定。**两者冲突时**：涉及期刊要求时期刊优先；不涉及期刊要求时，本文件的约定优先于通用默认值。

> **本文件只保留「通用规则中没有、或作者另有指定」的条目。** 通用层的符号排版、分组命名、术语一致性、动词强度、目的状语和占位符规则见 `editing-standard.md` 的 G4a、G9-G17，本文件不再重复。

## C.1 工作方式

### C.1.1 修改范围

**只修改被作者标记圈出的文字**，其余原样不动。圈外若确有必须修改之处，在回复中单列告知，不擅改原文。标记符号的形式可能改变，规则附着于「被标记」这一事实，而非某个特定符号。

### C.1.2 标记文本的语言处理

| 标记文本的语言 | 交付形式 |
|---|---|
| 中文 | 先润色中文，译为英文后再润色一遍（两个版本都给） |
| 中英混杂 | 中文润色版 + 英文润色版 |
| 纯英文 | 直接润色 |

### C.1.3 修订汇报格式

- **逐条平铺，不用分组表格**——作者明确表示分组表格「看不清楚」。每条只给三行：原句、改后、说明。
- 每一处删除都单独说明理由。
- 主题限定的修订清单不得混入无关内容；该主题触及不到的段落不得列入。
- 报告须与所述主题严格对应。作者曾明确纠正过「把不相关段落误列入某主题修订清单」这类组织错误。
- 修订说明与正文分开呈现，不把批注混进稿件文字。

### C.1.4 中文标记的解读

作者在标记文本内写的中文括注（形如「（……）」），是**要求整句以该中文为内容重写**，不是把括注并成一个从句附加在原句上。遇到英文句后跟中文括注时，须以括注内容**替换整句骨架**，不得只做局部增补。

## C.2 交付格式

- 稿件文字**不得使用粗体**（含 Markdown `**...**` 标记）。
- 斜体规则见 `editing-standard.md` 的 G12；本文件补充该作者的交付要求：
  - 分析说明文字中不滥用加粗强调，用标题与分点替代。
  - **需交付可直接粘贴的稿件时，优先生成 .docx**，仅给基因加斜体、无任何粗体。生成后须回读校验：粗体 run 数为 0，斜体仅出现在基因符号上。
  - 原因（作者明确说明）：Markdown 强调标记在粘贴进 Word 时会变成实际格式，导致整段变粗体加斜体。

## C.3 该作者的稿件专用约定

以下条目**内容随稿件而变**，此处只记录约定的类型与来源，不写入通用规则。

### C.3.1 术语

- **建模／干预操作用词**由作者指定（一旦确定，全稿一致）。用词选择须经作者确认，不因「更学术」而替换。
- **倍数**写作 `twofold` / `fivefold` / `threefold`（接数字时用 `-fold`），不用口语形式。
- **临床基础模型名称**由作者指定，全稿统一。
- **蛋白丰度**按蛋白语域表述，不用基因式表述（参见 `editing-standard.md` 的 G11b 和 G12）。

### C.3.2 句式

- **目的状语：少用，不是不用。** 作者指定本稿内降低 `To + 动词` 开目的句的频率；改由主句承担目的，或把目的状语移到主句之后。替换时须换到不同语法类别，不得只换词（参见 `editing-standard.md` 的 G9-G9a）。
- **段落开头不得堆叠名词**：主语与谓语之间不得隔两个或更多名词（参见 G16）。
- **已获作者认可的措辞是锚点**：只修有缺陷的部分，不重写已认可的部分（参见 G10f）。

### C.3.3 组名

三层结构见 `editing-standard.md` 的 G17。该作者的具体标签文字随稿件确定，不在本文件写死。

## C.4 项目级记录（不进通用技能）

以下内容属单篇论文或历史统计，**不得写入公开技能**，仅在本文件内作为工作记录保留：

- 具体论文名、图号、面板字母、基因名、实验分组名；
- 具体数值（样本量、频次、百分比、统计量）；

**存放位置**：这类内容应记入项目记忆或项目内的独立记录文件，**不进入 skill 目录**。本文件只保留 C.1–C.3 的可复用约定。
